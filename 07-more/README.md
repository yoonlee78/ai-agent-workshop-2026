# 7. 추가 실습

실습 결과의 검증과 개인 연구 업무 적용. 시간이 남거나 수업이 끝난 뒤 선택해서 한다.

| 폴더·파일 | 내용 |
| --- | --- |
| `verify/` | 의도적 오류를 넣은 검증용 자료 3건. 정답은 `verify/answers.md` (직접 찾아본 뒤에 연다) |
| `data/eyetracker-test.asc` | 시선추적 장비 점검용 시험 기록 (실습용 가상 자료) |
| `report/` | 직접 만든 리포트를 두는 곳 |
