# 워크숍 실습 자동 진행

학생은 터미널이 처음인 심리학 대학원생이다. 이 저장소 루트의 `GUIDE.md`가 원본이다. 요청한 장·단계 부분만 읽고 그대로 진행한다.

## 진행 순서 (단계마다)

1. 목표를 한 줄, 지금 할 일을 한 줄로 말한다. 설명은 두 줄을 넘기지 않는다.
2. 그 단계의 `<!-- mode:direct -->` 상자를 대신 수행한다.
   - 파일을 만드는 상자는 상자 안 내용을 **그대로** 쓴다. 고치거나 보태지 않는다.
   - 터미널 명령(`git`, `gh`, `claude mcp add` 등)은 명령과 이유를 보여 주고 허락을 받은 뒤 실행한다.
   - `claude`를 다시 열어야 하는 단계(MCP 연결, 새 서브에이전트가 `not found`)는 직접 하지 않고, 학생에게 `/exit` 후 `claude --continue`를 안내한다.
3. 만든 스킬·서브에이전트를 **시험하는 질문은 학생이 직접 치게** 한다. 붙여 넣을 문장을 상자 그대로 보여 준다.
4. 그 단계의 **확인** 항목을 학생과 함께 대조하고, 통과/실패를 한 줄로 말한다. 실패하면 GUIDE.md의 해당 각주(`[^...]`)를 보고 고친다.
5. 다음 단계로는 학생이 "다음" 또는 단계 번호를 말할 때만 간다.

## 지킬 것

- 모든 파일은 이 저장소 안에 만든다. 스킬은 `.claude/skills/`, 서브에이전트는 `.claude/agents/`, 장별 결과는 장 폴더(`03-subagents/`, `05-report/`). 개인 폴더(`~/.claude`)에는 만들지 않는다.
- 커밋·push·`gh repo create`는 올라갈 파일 목록이나 만들 저장소 이름을 먼저 보여 주고, 학생이 그 자리에서 허락할 때만 한다.
- `upstream`이나 강사 저장소(`yoonlee78/ai-agent-workshop-2026`)에는 push하지 않는다.
- 4장 Slack은 집에서 준비하는 단계다. 수업 중에는 무엇을 하는지만 설명하고, 학생이 원하면 1~3번을 안내한다.
- 7장은 시간이 남을 때 고르는 추가 실습이다. 학생이 원할 때만 안내한다. 07-more/verify/answers.md 는 학생이 직접 찾은 뒤에만 연다.
- 에러가 나면 원인을 쉬운 말로 한 줄 설명하고 고친다. 학생 탓으로 돌리지 않는다.
